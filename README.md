# Spotify Data Governance Framework

Ce repository contient l'ensemble des documents relatifs au projet de mise en place d'un cadre de gouvernance des données chez Spotify. Le projet vise à établir une structure pour la gouvernance des données.

## Documents du Projet

Analyse détaillée de l'écosystème data de Spotify :
- État des lieux de la maturité data
- Défis actuels en matière de gouvernance

### [2. Data Governance Policy Document](2_Data%20Governance%20Policy%20Document.pdf)
Document cadre définissant :
- Principes fondamentaux de gouvernance des données
- Structure organisationnelle et rôles

### [3. Detailed Implementation Plan](./3_Detailed%20Implementation%20Plan.pdf)

### [4. Organigramme Spotify](./4_organigramme_spotify.pdf)

### [5. Support Présentation](./support_presentation.pdf)
Support visuel pour la présentation du projet.

## Structure de Gouvernance

Le Center of Excellence (CoE) assure :
- La définition des standards et politiques
- Le support et l'expertise centralisés
- La coordination entre les départements
- Le suivi de la conformité

## Phase Pilote

Le déploiement commence par le département Marketing Europe.

## Technologies

Le projet s'appuie sur trois outils majeurs :
- Collibra : Catalogue de données
- Informatica : Qualité des données
- OneTrust : Gestion des consentements et conformité
